1. A penalty that can remove features

Lasso regression adds an absolute-coefficient penalty to squared error. Unlike ridge's smooth quadratic penalty, the absolute value has a corner at zero. That corner allows the optimum to contain coefficients that are exactly zero, producing a sparse linear model.

This can help when many candidate inputs are available but only a relatively small subset is expected to contribute useful signal. Examples include engineered feature libraries and high-dimensional measurement systems. Sparsity can simplify storage or interpretation, but a selected feature is not automatically a causal variable or a stable scientific discovery.

You will derive the subgradient condition, obtain soft thresholding for one coordinate, calculate a complete fit, and implement coordinate descent alongside a scikit-learn pipeline. Prerequisites are least squares and the idea of a derivative. The nonsmooth step is introduced explicitly.

2. Why a corner creates zeros

Ridge's penalty derivative approaches zero as a coefficient approaches zero. Lasso keeps exerting a constant-magnitude pull on every nonzero coefficient. At zero, a range of subgradient values is available. A feature whose correlation with the current residual is small enough can therefore satisfy optimality without moving away from zero.

\min_{\beta_0,\boldsymbol\beta}\left[\frac1{2n}\sum_i(y_i-\beta_0-\mathbf x_i^T\boldsymbol\beta)^2+\lambda\sum_j|\beta_j|\right]

The slopes β form a p-dimensional vector; β₀ is the unpenalized intercept; n is the training sample count; and λ ≥ 0 controls the penalty. The factor 1/2 simplifies derivatives and is part of the convention. Scikit-learn Lasso uses this convention, so alpha = lambda.

Standardization matters because the penalty is applied to coefficient units. Centering also lets us solve for slopes separately from the intercept. After fitting centered data, recover β₀ = y-bar − x-barᵀβ. Do not silently penalize a manually added constant column.

3. Subgradients and optimality

The derivative of |b| is +1 when b is positive and −1 when b is negative. At b = 0, a subgradient can be any number between −1 and 1. This interval captures supporting slopes to the convex absolute-value function.

\partial|b|=\begin{cases}\{1\}&b>0\\\left[-1,1\right]&b=0\\\{-1\}&b<0\end{cases}

For centered X and y, define the residual e = y − Xβ. Setting zero in the objective's subgradient gives Xᵀe/n = λs, where each entry sj belongs to the appropriate absolute-value subgradient.

\beta_j\ne0\Rightarrow\frac{\mathbf x_j^T\mathbf e}{n}=\lambda\operatorname{sign}(\beta_j),\qquad\beta_j=0\Rightarrow\left|\frac{\mathbf x_j^T\mathbf e}{n}\right|\leq\lambda

The column xj contains feature j over all observations. These are the KKT conditions for this convex problem. A zero coefficient is compatible with an entire interval of residual correlations. That interval, rather than a rounding heuristic, explains exact sparsity.

4. Derive a coordinate update

Hold all coefficients except βj fixed. Define the partial residual rj by removing the predictions of the other features. Let aj = xjᵀxj/n and zj = xjᵀrj/n. Ignoring terms that do not depend on b, the one-coordinate objective is ajb²/2 − zjb + λ|b|.

S(z,\lambda)=\operatorname{sign}(z)\max(|z|-\lambda,0),\qquad\beta_j\leftarrow\frac{S(z_j,\lambda)}{a_j}

For a positive solution, differentiate to obtain ajb − zj + λ = 0. This gives (zj − λ)/aj, valid only when zj > λ. The negative case gives (zj + λ)/aj when zj < −λ. Otherwise zero satisfies the subgradient condition. These three cases combine into soft thresholding.

If aj = 0, the centered feature is constant and should be removed or handled explicitly. With standardized nonconstant columns, aj is approximately one. Cycling through coordinates repeatedly solves the convex objective, subject to a convergence tolerance. Coefficient uniqueness is not guaranteed for arbitrary rank-deficient designs.

5. Calculate a sparse coefficient

Use centered x = [−1,0,1], y = [−2,0,2], and n = 3. There is one slope, a = 2/3, and z = 4/3. With λ = 1/3, soft thresholding gives S(4/3,1/3) = 1. Dividing by a gives slope 3/2.

Predictions are [−1.5,0,1.5]. Residuals are [−0.5,0,0.5], so MSE = 1/6 and the half-MSE term is 1/12. The L1 penalty is (1/3)·1.5 = 1/2. Total objective = 7/12. The OLS slope 2 has zero residual loss but penalty 2/3, so it is worse under this objective.

At λ ≥ 4/3, the coefficient becomes exactly zero. The model then predicts the mean target, zero. At x = 2 and λ = 1/3, the prediction is 3. If the observed target is 4, its residual is 1 and squared error is 1. Shrinkage creates bias even though it may help in noisier situations.

7. Coordinate descent and a pipeline

The downloadable script fits scaling on training data, implements cyclic coordinate descent, and compares its prediction vector with scikit-learn. The scratch implementation updates the residual efficiently after each coordinate change and checks convergence. It is educational code; production solvers additionally provide optimized sparse operations and more comprehensive optimality diagnostics.

"""Run with Python 3 after installing examples/requirements.txt."""
import numpy as np
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.linear_model import Lasso

from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

rng = np.random.default_rng(42)
X = rng.normal(size=(260, 6))
X[:, 1] = 0.8 * X[:, 0] + 0.2 * X[:, 1]
y = 2 + X @ np.array([2.5, 1.5, 0, 0, -1, 0]) + rng.normal(0, 0.8, 260)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42
)
scaler = StandardScaler().fit(X_train)
Z = scaler.transform(X_train)
Z_test = scaler.transform(X_test)
y_mean = y_train.mean()
yc = y_train - y_mean
n, p = Z.shape

def coordinate_descent(Z, yc, lam, rho, tolerance=1e-10, max_iter=50000):
    n, p = Z.shape
    beta = np.zeros(p)
    residual = yc.copy()
    mean_square = (Z * Z).mean(axis=0)
    for iteration in range(max_iter):
        previous = beta.copy()
        for j in range(p):
            residual += Z[:, j] * beta[j]
            z = Z[:, j] @ residual / n
            denominator = mean_square[j] + lam * (1 - rho)
            if denominator <= 0:
                beta[j] = 0
            else:
                beta[j] = (np.sign(z) * max(abs(z) - lam * rho, 0)
                           / denominator)
            residual -= Z[:, j] * beta[j]
        if np.max(np.abs(beta - previous)) < tolerance:
            return beta
    raise RuntimeError("Coordinate descent did not converge")

lam = 0.1
beta = coordinate_descent(Z, yc, lam, rho=1.0)
pred = y_mean + Z_test @ beta
pipe = make_pipeline(StandardScaler(), Lasso(alpha=lam, tol=1e-10, max_iter=50000))
pipe.fit(X_train, y_train)
np.testing.assert_allclose(pred, pipe.predict(X_test), atol=1e-6)
correlations = Z.T @ (yc - Z @ beta) / n
active = np.abs(beta) > 1e-8
np.testing.assert_allclose(correlations[active], lam * np.sign(beta[active]), atol=1e-7)
assert np.all(np.abs(correlations[~active]) <= lam + 1e-7)
print("Coefficients:", beta, "Nonzero:", np.count_nonzero(active))

print("Test MAE:", mean_absolute_error(y_test, pred))
print("Test RMSE:", np.sqrt(mean_squared_error(y_test, pred)))
print("Test R2:", r2_score(y_test, pred))

plt.scatter(y_test, pred, alpha=0.7)
limits = [min(y_test.min(), pred.min()), max(y_test.max(), pred.max())]
plt.plot(limits, limits, "k--", label="Perfect prediction")
plt.xlabel("Actual target")
plt.ylabel("Predicted target")
plt.legend()
plt.tight_layout()
plt.show()

A convergence warning should not be hidden. Increase the iteration budget, inspect feature scaling, reconsider a very small penalty, and check the solver's dual gap. Agreement between two implementations is useful, but a small optimality residual is a stronger diagnostic than apparent agreement alone.

8. Sparsity is not certainty

Lasso is attractive when a sparse approximation is useful and the feature space is large. A coordinate-descent pass for a dense n-by-p matrix is roughly O(np), while the number of passes depends strongly on correlation, penalty, tolerance, and implementation. Highly correlated features can make selection unstable: one feature may be selected in one sample and a near-duplicate in another.

The penalty biases retained coefficients toward zero. Refitting OLS on the selected features changes that bias but also changes the estimator and its variance. If selection and refitting are part of the procedure, validate the whole procedure. Conventional p-values computed as though feature selection never occurred are generally not justified.

A zero coefficient means the optimized model did not use that encoded feature at the selected penalty. It does not establish that the feature has no predictive value under another representation or conditional context. Interactions, nonlinear effects, measurement quality, and correlated alternatives can all affect selection.

Find the beginning of a regularization path

At the all-zero slope vector, the centered residual is simply y. The zero-coordinate KKT condition therefore holds for every feature exactly when λ is at least the largest absolute feature-target correlation in the objective's scaling.

\lambda_{\max}=\max_j\left|\frac{\mathbf x_j^T\mathbf y}{n}\right|

Here the term “correlation” means an inner product divided by n, not necessarily the dimensionless Pearson correlation. Features and target must use the same centering and scaling as the fit. At any λ at or above this value, the all-zero slopes satisfy the convex optimum conditions. The unpenalized intercept still predicts the training target mean.

A path algorithm can begin near this simple solution and gradually reduce λ, reusing the previous coefficients as a warm start. Because adjacent penalties often have similar solutions, this can be more efficient than solving each model from an unrelated initialization. Warm starting changes computational strategy, not the objective at a particular λ.

Check optimality instead of counting iterations

For nonzero coordinates, calculate the difference between xⱼᵀe/n and λ sign(βⱼ). For zero coordinates, calculate any excess of |xⱼᵀe/n| over λ. A small maximum violation gives a direct check that the reported coefficients approximately satisfy the KKT conditions. A small coefficient update alone can be less informative when the problem is poorly conditioned.

The executable example includes both a convergence criterion and a KKT check. With real data, a production solver's dual gap offers another global certificate of optimization accuracy. Tightening tolerances can increase runtime substantially without changing practical predictions, so select tolerances with awareness of the intended numerical precision rather than treating the smallest possible value as automatically best.

Distinguish a sparse prediction model from support recovery

Recovering the exact set of nonzero coefficients in a data-generating model is a stronger objective than predicting well. It requires assumptions about signal size, design correlations, noise, and penalty choice. A model can predict accurately while alternating between two nearly identical features, making its apparent support unstable.

Resampling can reveal this instability: fit the whole selection pipeline on several training resamples and record how often each feature is retained. These frequencies describe the chosen procedure on the available data. They are not posterior probabilities of causation, and simply averaging them does not create a formal selection guarantee.

If an application charges for collecting features, evaluate the complete acquisition policy. A selected feature may require a costly upstream measurement, while several apparently separate features may come from one inexpensive sensor. Lasso's coefficient count is only a proxy for operational simplicity when that cost structure actually matches the representation.

9. Interview questions

1. Why does lasso create exact zeros?

The L1 penalty has a subgradient interval at zero. Residual correlations within the interval can satisfy the optimum with a zero coefficient.

2. What is soft thresholding?

It subtracts the threshold from an input's magnitude, clips negative results to zero, and restores the original sign.

3. Does lasso have the ridge inverse formula?

No general matrix inverse formula handles the nonsmooth L1 penalty. Coordinate descent and other convex optimization methods are used.

4. When is the all-zero slope vector optimal?

For centered data, when λ is at least the largest absolute feature-target inner product divided by n.

5. Can correlated features cause instability?

Yes. Several similar features can substitute for one another, making the selected set sensitive to small data changes.

6. Is alpha equal to λ?

For scikit-learn Lasso and the half-MSE objective written here, yes. Other loss normalizations require rescaling.

7. Is feature selection evidence of causation?

No. It describes a penalized prediction fit, not an identified intervention effect.

8. What should you do with a convergence warning?

Inspect scaling, tolerance, iteration count, and the dual gap. Do not treat an unfinished optimization as a trustworthy selected model.

10. Practice and takeaways

  • Calculate the one-feature coefficient for λ = 0, 1/3, 1, and 4/3. Verify the threshold at which it becomes zero.
  • Duplicate an informative column and rerun across training splits. Compare coefficient stability and prediction stability separately.
  • Build a sparse engineered-feature model and report selection frequencies across resamples as descriptive evidence, not causal certainty.
  • Compare the scratch solver's KKT residual with its change-in-coefficients stopping rule.

Lasso couples numerical prediction with sparsity through a precisely defined nonsmooth objective. Interpret its zeros in the context of feature scaling, correlation, penalty selection, and uncertainty.
