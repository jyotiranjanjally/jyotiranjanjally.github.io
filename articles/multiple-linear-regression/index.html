Multiple Linear Regression — Matrix Mathematics and Implementation

Move from one feature to a design matrix. Understand projections, rank, the pseudoinverse, and stable numerical solutions.

1. From one predictor to many

A delivery-time model using distance alone ignores route conditions, load size, and time of departure. Multiple linear regression combines several predictors into one numerical estimate. It keeps the model linear in its coefficients while allowing each observation to have a vector of features.

You will learn to build a design matrix, derive the normal equations, understand why rank matters, and distinguish an algebraic formula from a stable implementation. The prerequisites are simple linear regression and basic matrix multiplication. The example uses synthetic features so that numerical issues can be inspected without a hidden data-cleaning process.

Multiple regression is useful for transparent baselines, calibration, resource estimation, and forecasting with known explanatory variables. It is also the foundation for regularized linear models. Adding features can reduce omitted structure, but a long feature list does not automatically remove confounding or make a predictive coefficient causal.

2. Add directions, then project

For each observation, multiply every feature by its coefficient and add the results. The intercept contributes the same amount to all rows. One feature creates a line; two create a plane in feature-target space. With more features, geometric visualization becomes difficult, but the algebra does not change.

A second geometric view is more useful. Treat the n observed targets as a vector in an n-dimensional observation space. Every design-matrix column is another vector in that space. The model can produce any linear combination of those columns. Least squares chooses the reachable vector closest to the target vector in Euclidean distance.

This column-space perspective explains both fitting and rank deficiency. If one feature column is exactly twice another, it adds no new prediction direction. The coefficients can trade off against each other while producing the same fitted target vector.

3. Matrix notation and dimensions

Let X have n rows and p + 1 columns, where the first column contains ones for the intercept. Each remaining column is a feature. Let β contain the intercept followed by p slopes, and let y contain the n targets.

X\in\mathbb R^{n\times(p+1)},\quad\boldsymbol\beta\in\mathbb R^{p+1},\quad\hat{\mathbf y}=X\boldsymbol\beta,\quad J(\boldsymbol\beta)=\frac1n\|\mathbf y-X\boldsymbol\beta\|_2^2

The squared L2 norm means the sum of squared vector entries. Matrix multiplication produces an n-entry prediction vector. Checking these dimensions is an effective debugging technique: multiplying X by a coefficient vector of the wrong length indicates that feature construction and model parameters disagree.

Expand the quadratic before differentiating. The scalar yᵀXβ equals its transpose βᵀXᵀy, so the two cross terms combine.

nJ=\mathbf y^T\mathbf y-2\boldsymbol\beta^TX^T\mathbf y+\boldsymbol\beta^TX^TX\boldsymbol\beta

4. Normal equations and rank

The derivative of the first term with respect to β is zero. The second term contributes −2Xᵀy. Because XᵀX is symmetric, the derivative of the final quadratic is 2XᵀXβ. Setting their sum to zero gives the normal equations.

\nabla J=\frac2n X^T(X\boldsymbol\beta-\mathbf y),\qquad X^TX\hat{\boldsymbol\beta}=X^T\mathbf y

These equations say that each column of X is orthogonal to the fitted residual vector. At the optimum, no small movement along an available feature direction can reduce squared error to first order.

\operatorname{rank}(X)=p+1\quad\Rightarrow\quad\hat{\boldsymbol\beta}=(X^TX)^{-1}X^T\mathbf y

The inverse formula requires full column rank. Having n ≥ p + 1 is necessary but not sufficient; duplicate columns still destroy rank. When X lacks full rank, least-squares predictions remain the unique projection onto its column space, but the coefficients need not be unique. The Moore–Penrose pseudoinverse selects the minimum-Euclidean-norm coefficient vector among the least-squares solutions.

X=U\Sigma V^T,\qquad X^+=V\Sigma^+U^T,\qquad\hat{\boldsymbol\beta}=X^+\mathbf y

The singular value decomposition uses orthonormal directions in U and V and nonnegative singular values in Σ. The pseudoinverse reciprocates the nonzero singular values. Numerical implementations use a tolerance to decide which tiny values should count as zero. Consequently, near-rank-deficient problems deserve inspection of the tolerance, feature scale, and sensitivity to perturbations.

5. Work through a two-feature fit

Consider four rows with features (0,0), (1,0), (0,1), and (1,1), and targets [1,3,4,6]. Including the intercept, the design rows are [1,0,0], [1,1,0], [1,0,1], and [1,1,1]. Direct multiplication gives:

X^TX=\begin{bmatrix}4&2&2\\2&2&1\\2&1&2\end{bmatrix},\qquad X^T\mathbf y=\begin{bmatrix}14\\9\\10\end{bmatrix}

The coefficient vector [1,2,3] solves the system: its products with the three rows of XᵀX are 14, 9, and 10. Predictions are [1,3,4,6], so every training residual and the training MSE are zero. This is an intentionally noiseless example, not a promise about real data.

At the new feature vector (2,1), the prediction is 1 + 2·2 + 3·1 = 8. If the observed outcome is 9, the residual is 1 and squared error is 1. Now add a duplicate column equal to twice the first feature. The predictions can stay identical while the corresponding coefficients change; the individual coefficients no longer have a unique solution.

6. Inspect what a linear fit misses

Residuals plotted against fitted values can expose structure that a linear feature set misses. The diagram varies an omitted quadratic component. It is a diagnostic illustration, not a statistical test. A systematic pattern is a reason to investigate features or functional form; lack of visible pattern is not proof of correctness.

7. Use stable numerical linear algebra

The script builds the intercept column explicitly for NumPy and uses lstsq. The scikit-learn model handles its intercept internally, so it receives the original feature matrix. Do not add a ones column and also ask a library to estimate an intercept without understanding the redundancy.

"""Run with Python 3 after installing examples/requirements.txt."""
import numpy as np
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.linear_model import LinearRegression

rng = np.random.default_rng(42)
X = rng.normal(size=(240, 3))
y = 1 + X @ np.array([2.0, -1.0, 0.5]) + rng.normal(0, 0.4, 240)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42
)
A_train = np.column_stack([np.ones(len(X_train)), X_train])
A_test = np.column_stack([np.ones(len(X_test)), X_test])
beta, residual_sums, rank, singular_values = np.linalg.lstsq(
    A_train, y_train, rcond=None
)
pred = A_test @ beta
model = LinearRegression().fit(X_train, y_train)
np.testing.assert_allclose(pred, model.predict(X_test), atol=1e-10)
np.testing.assert_allclose(A_train.T @ (y_train - A_train @ beta), 0, atol=1e-9)
print("Coefficients including intercept:", beta)
print("Rank:", rank, "Singular values:", singular_values)

print("Test MAE:", mean_absolute_error(y_test, pred))
print("Test RMSE:", np.sqrt(mean_squared_error(y_test, pred)))
print("Test R2:", r2_score(y_test, pred))

plt.scatter(y_test, pred, alpha=0.7)
limits = [min(y_test.min(), pred.min()), max(y_test.max(), pred.max())]
plt.plot(limits, limits, "k--", label="Perfect prediction")
plt.xlabel("Actual target")
plt.ylabel("Predicted target")
plt.legend()
plt.tight_layout()
plt.show()

Avoid calculating an explicit inverse as the default implementation. Forming XᵀX squares the condition number in the 2-norm for a full-rank matrix, making ill-conditioning worse. QR or SVD-based least-squares routines are more reliable. A dense solve is commonly on the order of np² when n is larger than p, with details depending on the decomposition and dimensions.

8. Interpret coefficients conditionally

A multiple-regression slope describes the fitted change in prediction per unit of one feature while the other encoded features are held fixed. If features are highly correlated, that hypothetical change may be rare or unsupported in the observed data. Coefficients can therefore be unstable even while predictions within the observed feature manifold remain stable.

Feature scaling changes coefficient units. A coefficient on standardized temperature represents a change per training standard deviation, not per degree. Categorical predictors require an encoding with a reference or another identifiable parameterization. An intercept plus every one-hot indicator for a category creates an exact linear dependence.

Adding irrelevant features never increases the minimum training squared error because the old solution remains available with zero coefficients on the new columns. Test error can increase as estimation variance grows. Training improvement alone is therefore not a sufficient feature-selection criterion.

Recover a conditional coefficient by residualization

A useful way to understand “holding other features fixed” is to remove their linear contribution before fitting the feature of interest. Suppose x₁ is the column whose coefficient you want, and Z contains the intercept and every other predictor. Regress x₁ on Z and retain its residual rₓ. Separately regress y on Z and retain residual rᵧ. The slope from regressing rᵧ on rₓ is the coefficient of x₁ in the full regression.

M_Z=I-ZZ^+,\qquad\hat\beta_1=\frac{\mathbf x_1^TM_Z\mathbf y}{\mathbf x_1^TM_Z\mathbf x_1}=\frac{\mathbf r_x^T\mathbf r_y}{\mathbf r_x^T\mathbf r_x}

The matrix MZ removes the projection onto the column space of Z, and Z⁺ is its pseudoinverse. This result assumes the residualized feature has nonzero variation. If rₓ is zero, the feature is fully explained by the other columns and its separate coefficient is not identified. Residualization therefore exposes the information problem behind multicollinearity.

For a small illustration, take centered x₁ = [−1,−1,1,1] and x₂ = [−1,1,−1,1]. They are orthogonal. Let y = 2x₁ + 3x₂ = [−5,1,−1,5]. Removing the x₂ component leaves rᵧ = 2x₁. The residualized slope is x₁ᵀ(2x₁)/(x₁ᵀx₁) = 8/4 = 2, matching the full model. If x₂ were instead identical to x₁, that separate calculation would have a zero denominator.

Feature encoding is part of the model

A categorical variable with three levels can be represented by an intercept and two indicator columns. The intercept then represents the reference category at zero values of the remaining numerical features, and the two coefficients represent conditional differences from that reference. Changing the reference changes the coefficients but can leave every prediction unchanged.

An interaction column x₁x₂ changes the interpretation further. In a model containing β₁x₁ + β₂x₂ + β₁₂x₁x₂, the fitted change with respect to x₁ is β₁ + β₁₂x₂. There is no single constant effect of x₁ across all x₂ values. Including the component main effects usually makes the interaction interpretation more coherent, although the appropriate representation depends on the domain.

Document the exact training column order and transformation rules. A numerically valid matrix with swapped columns can produce incorrect predictions without raising a shape error. Named DataFrame columns and a fitted preprocessing pipeline help preserve that contract, but schema validation remains valuable at the interface.

9. Interview questions

1. What does the normal equation mean geometrically?

The fitted residual vector is orthogonal to every design-matrix column. The predictions are the orthogonal projection of y onto the column space of X.

2. Is n greater than p enough for invertibility?

No. Full column rank is also required, including the intercept column. Duplicate or linearly dependent features can make XᵀX singular with arbitrarily many rows.

3. What does the pseudoinverse choose?

The minimum-L2-norm coefficient vector among all least-squares solutions. It does not create information that dependent features lack.

4. Why avoid the explicit inverse?

Solving the least-squares system directly is generally more stable and efficient. Forming the Gram matrix worsens conditioning and an inverse is not needed to compute the solution.

5. Can coefficients be unstable while predictions are stable?

Yes. Correlated feature directions allow large coefficient changes that mostly cancel on the observed input distribution.

6. Is multiple regression nonlinear?

It is linear in its coefficients. The feature columns themselves may encode nonlinear transformations, which changes linearity with respect to the original inputs.

7. What happens when p exceeds n?

The unregularized system cannot have full column rank. There can be many solutions, possibly including exact interpolators. Regularization or explicit constraints become especially important.

8. Does a coefficient measure causal effect?

Only under a justified causal design and identification assumptions. Conditional association in a fitted prediction model is not sufficient.

10. Practice and takeaways

  • Add a duplicate feature to the script. Compare rank, coefficient vectors, and predictions from the pseudoinverse and scikit-learn.
  • Multiply one feature by one million. Inspect numerical conditioning and explain why the prediction function can remain the same while coefficient units change.
  • Create a resource-consumption mini-project with two meaningful predictors and a documented categorical encoding.
  • Verify Xᵀe is approximately zero on the training set. Explain why the same identity need not hold on the test set.

Matrix notation reveals the structure of regression. Rank determines coefficient uniqueness; numerical conditioning determines sensitivity; evaluation determines whether the resulting prediction function is useful.
