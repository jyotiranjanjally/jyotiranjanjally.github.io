1. One feature, one interpretable line

Simple linear regression models a numerical target using one numerical feature. It is useful when a straight line is a reasonable local approximation: energy use over a limited temperature range, manufacturing cost against batch size, or travel time against distance within a region. Its small number of parameters makes it an excellent starting point for understanding estimation.

You will derive the ordinary least-squares slope and intercept, connect the formula to covariance, solve a small dataset by hand, and compare a NumPy implementation with scikit-learn. You need means, sums, and basic differentiation. “Simple” means one predictor; it does not mean the assumptions or interpretation are trivial.

2. Balance the line through the cloud

Imagine drawing a line through a scatterplot. Moving the intercept shifts every prediction by the same amount. Changing the slope rotates the line: a one-unit increase in x changes the predicted y by the slope. Least squares chooses the line that minimizes the sum of squared vertical residuals.

The distances are vertical because the objective treats x as given and predicts y. Minimizing perpendicular geometric distances is a different optimization problem. If the feature itself contains substantial measurement error, the ordinary least-squares interpretation can fail; the fitted slope may be attenuated toward zero under classical measurement-error conditions.

\hat y_i=\beta_0+\beta_1x_i,\qquad J(\beta_0,\beta_1)=\frac{1}{n}\sum_{i=1}^{n}(y_i-\beta_0-\beta_1x_i)^2

The intercept β₀ is the prediction at x = 0. The slope β₁ has units of target per unit of feature. There are n observations indexed by i. J is mean squared training error. An intercept can be algebraically meaningful even when zero lies outside the observed range; its real-world interpretation then requires caution.

3. Derive ordinary least squares

First differentiate with respect to the intercept. Each residual contributes −2 times itself, divided by n. Setting the sum to zero says the fitted residuals have mean zero.

\frac{\partial J}{\partial\beta_0}=-\frac{2}{n}\sum_i(y_i-\beta_0-\beta_1x_i)=0\quad\Rightarrow\quad\hat\beta_0=\bar y-\hat\beta_1\bar x

The bars denote sample means. Substitution shows that the fitted line passes through (x-bar, y-bar). This is a training-set identity for unconstrained OLS with an intercept, not a guarantee that test residuals average to zero.

Now differentiate with respect to the slope and substitute the intercept expression. This centers both variables and eliminates the constant component.

\frac{\partial J}{\partial\beta_1}=-\frac{2}{n}\sum_i x_i(y_i-\beta_0-\beta_1x_i)=0
\sum_i(x_i-\bar x)(y_i-\bar y)=\hat\beta_1\sum_i(x_i-\bar x)^2\quad\Rightarrow\quad\hat\beta_1=\frac{\sum_i(x_i-\bar x)(y_i-\bar y)}{\sum_i(x_i-\bar x)^2}

The numerator measures how x and y vary together; the denominator measures how much x varies. Dividing sample covariance by sample variance gives the same ratio because their common normalization cancels. If every x is identical, the denominator is zero and slope and intercept cannot be uniquely separated. No optimizer can recover variation absent from the data.

The loss is a convex quadratic. When the feature has nonzero variance, the design matrix consisting of ones and x has full column rank, so this stationary point is the unique global minimum. A local optimization algorithm is unnecessary for this tiny problem. The formula requires two passes over the data if means are computed first, and constant additional storage beyond the inputs.

4. Solve a complete dataset by hand

Use x = [1, 2, 3] and y = [2, 3, 5]. The means are x-bar = 2 and y-bar = 10/3. The centered x values are [−1, 0, 1]; the centered y values are [−4/3, −1/3, 5/3]. Their cross-products sum to 4/3 + 0 + 5/3 = 3. The squared centered x values sum to 2.

Therefore the slope is 3/2 and the intercept is 10/3 − (3/2)·2 = 1/3. Predictions are [11/6, 10/3, 29/6]. The residuals are [1/6, −1/3, 1/6], which sum to zero. Their squared sum is 1/36 + 1/9 + 1/36 = 1/6, and MSE is 1/18.

For a new x = 4, the prediction is 1/3 + (3/2)·4 = 19/3, approximately 6.333. If the subsequently observed target is 6, the residual is −1/3 and its squared error is 1/9. That error is a new observation's error, separate from the fitted training MSE.

Check the slope's units. If x is distance in kilometres and y is minutes, 1.5 means 1.5 predicted additional minutes per additional kilometre within the model's scope. It does not imply that changing distance while holding all real-world conditions fixed causes exactly that effect.

5. Explore slope and loss

Squared loss penalizes an overprediction and an underprediction of the same magnitude equally. Errors of opposite sign cannot cancel after squaring. Notice how a line can visibly miss a few points without producing the largest total loss: both the number and size of residuals matter.

6. Fit from scratch and with scikit-learn

The following complete script estimates the slope using centered dot products on the training subset. It checks the denominator explicitly, then verifies that its predictions agree with scikit-learn's linear model. The agreement is a numerical correctness check, not an accuracy claim about an external dataset.

Download the complete Python script ↓ · Python requirements

"""Run with Python 3 after installing examples/requirements.txt."""
import numpy as np
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score
from sklearn.linear_model import LinearRegression

rng = np.random.default_rng(42)
X = rng.uniform(-3, 3, size=(200, 1))
y = 1.2 + 2.5 * X[:, 0] + rng.normal(0, 0.8, 200)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42
)
x = X_train[:, 0]
xc = x - x.mean()
yc = y_train - y_train.mean()
denominator = xc @ xc
if denominator <= 0:
    raise ValueError("A nonconstant feature is required")
slope = (xc @ yc) / denominator
intercept = y_train.mean() - slope * x.mean()
pred = intercept + slope * X_test[:, 0]
model = LinearRegression().fit(X_train, y_train)
np.testing.assert_allclose(pred, model.predict(X_test), atol=1e-10)
print("Intercept and slope:", intercept, slope)

print("Test MAE:", mean_absolute_error(y_test, pred))
print("Test RMSE:", np.sqrt(mean_squared_error(y_test, pred)))
print("Test R2:", r2_score(y_test, pred))

plt.scatter(y_test, pred, alpha=0.7)
limits = [min(y_test.min(), pred.min()), max(y_test.max(), pred.max())]
plt.plot(limits, limits, "k--", label="Perfect prediction")
plt.xlabel("Actual target")
plt.ylabel("Predicted target")
plt.legend()
plt.tight_layout()
plt.show()

Both implementations fit an intercept. If you instead center the training features and targets, fit a model without an intercept, and then reconstruct predictions, you must restore the target mean and apply the same training-derived feature centering to the test set. Centering the test data by its own mean changes the prediction function.

7. What the solution does and does not assume

The numerical minimizer exists without assuming that the residuals are Gaussian. For an unbiased estimate of a correctly specified linear conditional mean, a central condition is zero conditional mean error: the unexplained component has expectation zero given the feature. Correlation between the feature and omitted influences can invalidate this interpretation.

Constant error variance is used for the usual homoscedastic standard-error formulas and the classical efficiency result. It is not required to compute the line. Independent or appropriately modelled observations are important for inference and evaluation. Daily observations from one machine are not necessarily independent replicates.

Normal conditional errors support exact t-based finite-sample inference under the other classical assumptions. Prediction itself can still be useful when errors are not normal. Always distinguish “the algorithm can run,” “the coefficients estimate the intended quantity,” and “a particular uncertainty formula is justified.”

8. Advantages, limitations, and engineering choices

The model is fast, transparent, and easy to debug. A small training dataset can be enough to inspect its behaviour, and the coefficient formula reveals exactly how observations influence the answer. It is a strong baseline when the signal is approximately monotonic and locally linear.

It is sensitive to outliers because squared loss gives large residuals a large contribution. A point far from the feature mean has high leverage and can rotate the line substantially. A high-leverage point need not have a large residual, so inspecting only the residual magnitude is insufficient.

A single slope cannot capture saturation, thresholds, or interactions. Adding a polynomial basis or additional predictors may help, but first inspect whether the extra flexibility addresses a visible and plausible problem. Avoid assuming that a high R² makes extrapolation safe. Predictions far outside the training range rely heavily on the structural form of the model.

Derive the coefficient uncertainty under classical assumptions

The point estimate alone does not tell us how much it would change across repeated samples. Under a correctly specified line with independent zero-mean errors of common variance σ², the slope variance is σ² divided by the sum of squared centered feature values. More spread in x provides more information about slope, while larger unexplained variation makes estimation harder.

S_{xx}=\sum_i(x_i-\bar x)^2,\qquad\operatorname{Var}(\hat\beta_1\mid X)=\frac{\sigma^2}{S_{xx}},\qquad s^2=\frac{\sum_i e_i^2}{n-2}

Here s² estimates the error variance using residual degrees of freedom n − 2, because the line has two fitted parameters. This requires n > 2 and nonzero feature variation. The quantity s² differs from training MSE, whose denominator is n. One estimates the assumed noise variance; the other summarizes the fitted prediction errors on those rows.

For a feature value x₀, uncertainty about the estimated mean line depends on both sample size and distance from the feature mean. The conditional variance of the estimated mean response is σ²[1/n + (x₀ − x-bar)²/Sxx]. Predicting a new noisy observation adds another σ² term. This explains why a prediction interval is wider than a confidence interval for the mean under the same model.

For the three-point worked example, SSE = 1/6 and n − 2 = 1, so s² = 1/6. The estimated slope standard error is √((1/6)/2) = √(1/12), approximately 0.289. That arithmetic is valid under the stated model, but one residual degree of freedom gives very weak information about uncertainty. A narrow-looking scatterplot with three points should not inspire strong conclusions.

Distinguish interpolation from information

Collecting more observations at exactly the same feature value can improve estimation of a local mean but cannot identify a slope by itself. Conversely, collecting a few observations far apart increases Sxx but may expose nonlinear behaviour that invalidates a single-line assumption. Experimental range and model adequacy must be considered together.

If you transform units, uncertainty transforms with the coefficient. Converting kilometres to metres divides both the slope and its standard error by one thousand; the ratio used by a conventional slope test remains unchanged. This is a useful consistency check and a reminder that coefficient magnitude alone cannot measure importance across differently scaled features.

9. Interview questions

1. Why does the line pass through the sample means?

The intercept's first-order condition forces the sum of training residuals to zero, giving β₀ = y-bar − β₁x-bar.

2. What happens when all x values are equal?

The design matrix is rank deficient. A constant fitted prediction can be identified, but infinitely many slope-intercept pairs produce it.

3. Is slope equal to correlation?

Not generally. The slope equals correlation times the ratio of target standard deviation to feature standard deviation. Correlation is dimensionless; slope depends on units.

4. Why square residuals?

Squaring produces a differentiable convex objective, avoids sign cancellation, and emphasizes large errors. It also corresponds to conditional-mean prediction under expected squared loss.

5. Does OLS require gradient descent?

No. This problem has an analytic solution. Numerical linear algebra is also available; iterative optimization is useful in other computational settings.

6. What changes if x is measured in metres instead of kilometres?

The slope becomes one thousandth as large. Predictions remain identical if inputs and coefficients are transformed consistently.

7. Do test residuals sum to zero?

Not necessarily. The zero-sum identity comes from fitting the intercept on the training targets, not from a constraint on future observations.

8. Can a zero slope establish no relationship?

No. It establishes no fitted linear association in that sample. A symmetric quadratic relationship can have a near-zero linear slope while being strongly predictable.

10. Practice and takeaways

  • Reproduce the three-point example with fractions, then verify it numerically with the downloaded script.
  • Add one point at x = 20 with an unusually low target. Compare the fitted line with and without that observation and explain leverage.
  • Fit y = x² on a symmetric feature interval. Explain why a near-zero slope does not imply independence.
  • Build an energy-use baseline and inspect residuals against temperature before proposing a more complicated estimator.

OLS estimates a line by making residuals orthogonal to the constant and feature directions. Its closed-form solution is simple; its interpretation depends on the data-generating setting, evaluation design, and the limits of a straight-line approximation.
